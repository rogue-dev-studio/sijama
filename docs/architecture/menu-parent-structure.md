# Menu parent structure

| Parent | Anak (ringkas) |
|--------|----------------|
| Informasi | Dashboard, Kehadiran, Kategori Umur, Kalender |
| Laporan | *(belum ada modul)* |
| Transaksi | Pengajian, Kegiatan, Absensi |
| Master | Jamaah; Wilayah Fungsional; Wilayah Administrasi |
| Aplikasi | Dapukan, Menu, Fitur, Hak Akses, Matriks, Pengguna |

Top-level parent **hanya** kelima di atas. Subgrup wilayah ada di bawah Master, bukan root.
