# Jamaah Kelompok — tanpa Master

Tanggal: 2026-08-24

## Perilaku

Dapukan `jamaah_kelompok` (tanpa dapukan lain) **tidak** mendapat `jamaah.view` / `lokasi.view`, sehingga section **Master** tidak muncul.

Akses yang tetap ada:
- Informasi: Dashboard, Kehadiran, Kategori Umur, Kalender
- Transaksi: Pengajian (view), Kegiatan (view)

Permission digabung dari semua dapukan efektif pada jamaah. Jika ada dapukan tambahan (mis. Admin Kelompok), menu mengikuti union hak akses.
