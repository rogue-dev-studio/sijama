# Kalender Informasi — QA / AC

Date: 2026-08-04

## Acceptance criteria

1. Menu **Informasi → Kalender** muncul setelah login (permission `kalender.view`); path `/kalender`.
2. Tampilan **bulanan** dalam **card/panel**; filter **Bulan** (dropdown) & **Tahun** (input angka tanpa batas rentang); tombol **Hari ini** untuk lompat ke tanggal hari ini.
3. Header nama hari punya **background**; kolom **Jumat** highlight solid (bukan transparan).
4. **Minggu** punya background solid + angka merah; **hari libur** punya background solid + angka merah.
5. Daftar libur di bawah grid: **tanggal + nama** berwarna merah (jenis/Hijri tetap muted).
6. Marker kegiatan/pengajian di dalam sel (dot warna); multi-event + overflow `+N`; klik sel membuka detail.
7. Angka Masehi + label Hijri di sel (Hijri disembunyikan di mobile sempit).
8. **Legend** menampilkan **semua** kategori kegiatan aktif (meski tidak ada event di bulan tersebut).
9. Status otomatis: command `events:update-statuses` dijadwalkan tiap 5 menit via service Docker `scheduler`.

## Status auto rules

- Kegiatan `planned` → `ongoing` pada hari `tanggal`; → `completed` setelah hari lewat; `cancelled` tidak diubah.
- Pengajian `scheduled` → `completed` setelah `ends_at` (atau `starts_at` jika `ends_at` null).

## Manual check

- Login `admin` / `password`, buka Kalender: card, dropdown bulan/tahun, header hari, Jumat/Minggu/libur solid.
- Bulan tanpa kegiatan: legend tetap penuh dari master kategori.
- List libur: tanggal & nama merah.
- `docker compose exec backend php artisan events:update-statuses`
